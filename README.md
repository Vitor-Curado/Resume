# Resume builder using LaTeX and VS Code

This is... uh... my resume repo for absolute shits and giggles. Upon running, it generates a new folder "build" that should contain the resume with the same name as `vitor-resume.tex` (the master file). Changing the master file's name changes the resume's name.

It is thoroughly organised, but it may simply be lumped into one huge file for convenience and/or for rapid resume tailoring with LLMs. Not sure about agents, though.
