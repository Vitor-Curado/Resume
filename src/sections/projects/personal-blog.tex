\textbf{Personal blog} \hfill \textit{Rust, TypeScript, React, PostgreSQL, Docker, GitHub Actions, AWS EC2, AWS S3, GHCR}

\begin{itemize}
    \item Designed and developed a server-rendered personal publishing platform in Rust, separating request handling, application logic, persistence, and presentation into modular components.
    \item Implemented asynchronous request handling and database-backed content management with PostgreSQL, designing application interfaces around clear separation of concerns and predictable error handling.
    \item Developed the frontend using TypeScript and React while gradually transitioning the application from server-rendered pages toward a client-rendered architecture to reduce server-side workload and hosting costs.
    \item Containerized the application with Docker and established a CI/CD pipeline using GitHub Actions to build, test, publish, and deploy reproducible application images through GitHub Container Registry.
    \item Deployed the application to AWS EC2 and integrated Amazon S3 for persistent object storage, separating application infrastructure from user-uploaded and static assets.
\end{itemize}
