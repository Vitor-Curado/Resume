\textbf{Static webpage} \hfill \textit{JavaScript, Node.js, Express.js, HTML, CSS, Docker, GitHub Actions, AWS EC2}

\begin{itemize}
    \item Developed a lightweight website using HTML, CSS, and JavaScript, using static generation to prioritize simplicity, ease of maintenance, and low operating costs.
    \item Used Node.js and Express.js as the development and generation environment while keeping the resulting deployment simple and inexpensive.
    \item Containerized the application with Docker and configured GitHub Actions to automate validation and deployment of changes to an AWS EC2 instance.
\end{itemize}
