\textbf{Desktop financial application} \hfill \textit{C++, Qt, PostgreSQL}

\begin{itemize}
    \item Developing a native C++ desktop application for tracking precious-metal purchases, quantities, purchase prices, and historical transaction data.
    \item Designed the application around a persistent PostgreSQL data model and a Qt-based graphical interface, separating presentation, application logic, and database operations.
    \item Implementing application workflows for recording purchases and retrieving historical data while maintaining a structure that can accommodate additional financial tracking functionality.
\end{itemize}
