\textbf{Desktop financial application} \hfill \textit{C++, Qt, PostgreSQL}

\begin{itemize}
    \item Chose C++ for a native desktop implementation, pairing its performance and systems-level control with Qt's cross-platform application framework.

    \item Built the graphical interface with Qt, separating presentation concerns from application and persistence logic to keep the desktop application maintainable.

    \item Designed PostgreSQL storage for transaction records, preserving quantities, purchase prices, and historical data for retrieval, comparison, and future analysis.
\end{itemize}
