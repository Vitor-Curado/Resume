\textbf{Password manager} \hfill \textit{Rust, SQLite}

\begin{itemize}
    \item Chose Rust for the application core, leveraging memory safety and strong compile-time guarantees for software handling sensitive credential data.
    \item Built the graphical interface with egui, favoring a lightweight and ergonomic development model appropriate for a local desktop application.
    \item Used SQLite for persistent storage, keeping credentials local to the application and avoiding the operational complexity of a remote service.
\end{itemize}
