\textbf{Password manager} \hfill \textit{Rust, SQLite}

\begin{itemize}
    \item Developing a desktop password manager in Rust with a native graphical interface built using egui and persistent local storage backed by SQLite.
    \item Designing the application around encrypted credential storage, explicit separation between sensitive data and presentation logic, and a local-first architecture that does not require a remote service.
    \item Implementing password-management workflows for creating, retrieving, editing, and organizing credentials while investigating practical approaches to secure key and secret handling.
\end{itemize}
