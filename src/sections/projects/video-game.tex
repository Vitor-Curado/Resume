\textbf{Minecraft server} \hfill \textit{Rust}

\begin{itemize}
    \item Developing a multiplayer Minecraft server in Rust to explore network programming, client-server architecture, asynchronous I/O, and concurrent state management.
    \item Implementing server-side connection handling and protocol processing while maintaining application state for multiple connected clients.
    \item Designing the server around modular networking and game-state components to allow additional protocol and gameplay functionality to be implemented incrementally.
\end{itemize}
